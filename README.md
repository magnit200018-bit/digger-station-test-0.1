# Digger Station — Prototype 0.1

Первый игровой прототип Digger Station: одиночное исследование заброшенного объекта от первого лица. Это ранний тест управления и атмосферы, а не финальная игра.

## Как запустить

### Самый простой способ
1. Скачай все файлы проекта.
2. Открой папку в редакторе кода, например Visual Studio Code.
3. Запусти через расширение **Live Server** (правой кнопкой по `index.html` → **Open with Live Server**).
4. Играй в браузере на компьютере.

Важно: проект использует Three.js с CDN, поэтому для запуска нужен интернет. Простое открытие `index.html` двойным кликом может не сработать из-за ограничений браузера на ES-модули.

### Запуск через GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи в корень репозитория `index.html`, `style.css`, `game.js` и `README.md`.
3. Открой **Settings → Pages**.
4. В разделе сборки выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем сохрани.
5. Подожди публикации и открой ссылку, которую покажет GitHub Pages.

## Управление
- **W / A / S / D** — движение.
- **Мышь** — осмотр.
- **E** — взаимодействовать с объектом.
- **F** — включить/выключить фонарь.
- **Shift** — двигаться быстрее.
- **Esc** — отпустить курсор мыши.

## Что есть в билде 0.1
- Простая 3D-база Digger Station.
- Снаряжение, карта объекта, записка и дверь на вылазку.
- Заброшенный бункер с исследуемыми предметами.
- Сбор находок и увеличение репутации.
- Подозрительный вентиляционный проём и первая реплика о дежавю.
- Возвращение на базу с результатами вылазки.
- Лёгкая графика, рассчитанная на запуск в браузере.

## Что пока не реализовано
- NPC и диалоги с историей трубы.
- Случайные прогнозы труб и система риска смерти.
- Полный сброс прохождения при гибели.
- Большой набор локаций, сохранения и улучшение базы.
- Финальная система лута и экономика.

Механика «трубы смерти» пока обозначена как загадочный объект — она будет отдельным этапом разработки после проверки базового управления.

## Изменения в 0.1

- Добавлены база, бункер, управление от первого лица, взаимодействия, фонарь и находки.
- Добавлен первый намёк на дежавю.
