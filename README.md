# Digger Station — Prototype 0.1.2

Первый игровой прототип: одиночное исследование базы и заброшенного бункера от первого лица.

## Запуск через GitHub Pages
Загрузите `index.html`, `style.css`, `game.js` и `README.md` прямо в корень репозитория. В Settings → Pages выберите ветку `main` и папку `/ (root)`.

## Управление
- `W A S D` — движение
- Стрелки — движение
- Мышь — осмотр по сторонам (клик по игровому окну захватывает мышь)
- `E` — взаимодействие с объектом в центре экрана в пределах досягаемости
- `F` — фонарь
- `Shift` — ускорение
- `Esc` — отпустить мышь

Игра использует Three.js с CDN, поэтому нужен интернет. Это ранний прототип; полноценная механика трубы смерти и NPC пока не реализована.
